# Gold Coast SUP & Surf Repair

Учебный многостраничный статический сайт для практических работ по интернет-технологиям, SEO и веб-аналитике.

## Стек

- HTML5
- CSS3
- Vanilla JavaScript
- JSON-LD Schema.org
- GitHub Pages
- Без React, Node.js, базы данных и серверной части

## Страницы

- `index.html` — главная
- `services.html` — услуги и starting prices
- `sup-repair.html` — ремонт SUP
- `surf-ding-repair.html` — ремонт серфбордов
- `contacts.html` — контакты и drop-off
- `thank-you.html` — подтверждение демонстрационной формы
- `404.html` — кастомная 404
- `privacy.html` — учебная Privacy Policy

## Локальный запуск

Самый простой способ — открыть `index.html` в браузере.

Для более реалистичного локального теста GitHub Pages можно использовать любой простой статический HTTP-сервер. Серверная часть сайту не требуется.

## Формы

Формы работают только в браузере. После успешной клиентской валидации выполняется переход на `thank-you.html`. Никакие данные не отправляются и не сохраняются.

## Аналитика

В `<head>` каждой HTML-страницы оставлен комментарий:

`<!-- Paste Yandex Metrica and Google Analytics 4 scripts here -->`

В `script.js` находится:

`const COUNTER_ID = 'YOUR_METRICA_COUNTER_ID';`

Перед реальной учебной настройкой Яндекс.Метрики замените placeholder на ID счётчика. Вызов `ym()` выполняется только если функция существует.

Для GA4 вставьте официальный gtag-код и замените Measurement ID на нужный учебный идентификатор.

События:

- `phone_click`
- `estimate_cta_click`
- `repair_estimate_submit`
- `location_click`

## GitHub Pages

1. Создайте публичный GitHub repository.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите публикацию из ветки `main`, папка `/root`.
5. Дождитесь публикации.
6. Используйте выданную GitHub Pages ссылку в учебном отчёте.
7. Если нужен кастомный домен, замените canonical/OG/robots/sitemap значения после подключения домена.

## Перед сдачей

Проверьте и при необходимости замените:

- placeholder-домен `goldcoastsuprepair.com.au`;
- учебные контактные данные;
- ссылки на тематические изображения Unsplash;
- `YOUR_METRICA_COUNTER_ID`;
- GA4 Measurement ID;
- карту и внешние ссылки;
- даты, если учебный проект будет опубликован после 2026 года.
